# Feed Detachments Prototype

Mobile-first React prototype demonstrating Facebook "Feed Detachments" — separate tap targets for post media and link attachments.

## Run locally

```bash
cd ~/Projects/feed-detachments-prototype
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Interactions

- **Media** — tap photos or video poster to open the media viewer
- **Attachment row** — tap thumbnail/title/metadata to navigate to the event or Marketplace detail page
- **CTA button** — tap "Interested" or "Save" to toggle inline without leaving the feed
